How many cards exist

A card is an arrangement, not a bag: the same squares in different places win on different lines, so two cards holding the same list are two different cards.

Type your squares one per line, and the panel above counts every card that list can make. Then say how many you want and press Deal the cards: each one is a different arrangement, no two alike, and the PDF puts one on every page. The seed is printed on the cards, so the same set can be dealt again. Nothing leaves your browser — the PDF is written here, byte by byte.
