Neuron Bench

A neuron is a function that multiplies each input by a weight, adds them up with a bias, and puts the total through one bend. That is the whole thing. Everything a network can do comes from stacking that.

Start at the first lesson and work along. Every control stays live afterwards, so a lesson is a starting point rather than a mode: change the number of neurons, change the bend, break it on purpose.

Your own data

CSV, one row per example. Every column but the last is an input and must be a number; the last column is the answer. A numeric last column with many distinct values is treated as a regression, anything else as classes. Nothing is uploaded — the file is read in this tab.

Runs entirely in this tab: the network is trained on your machine, in a background thread, and nothing about it is sent anywhere. Tree measurements come from the Vienna Baumkataster (Stadt Wien, CC BY 4.0), trimmed to the eight commonest species and the numeric columns. The network, the training and every plot are written from scratch for this page.
