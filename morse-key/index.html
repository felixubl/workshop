The alphabet

56 characters

Morse has one length in it, the dit, and everything else is counted in dits. A dah is three. The gap inside a letter is one, between letters three, and between words seven. So the whole code is a rhythm rather than an alphabet, and two operators at different speeds send the same thing as long as the ratios hold. The speed dial sets how long a dit is in milliseconds — at twelve words a minute it is a tenth of a second — and everything else follows from it.

A press is read as a dah past two units, and a silence ends the letter past two and adds a word space past five. Those are the midpoints between the lengths the code defines, so they are where the guess is least likely to be wrong. If your letters keep running together or breaking apart, the dial is set to somebody else's speed rather than yours; the measured reading beside it, and the match button, are there for that.

A pattern with no character against it is printed in angle brackets the way an operator writes a prosign, so nothing is silently dropped. Backspace clears the letter you are part way through, or removes the last one if you are between letters.
